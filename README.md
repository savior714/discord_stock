# Discord 주가 알람 봇

yfinance를 활용하여 기술적 지표 기반 매수 시점을 감지하고 Discord로 실시간 알림을 전송하는 자동화 봇입니다.

## 📊 주요 기능

### 🎯 기술적 지표 모니터링
세 가지 조건을 **모두 만족**할 때만 알람 발생:
- **RSI(14) < 35**: 과매도 구간 진입
- **MFI(14) < 35**: 자금 흐름 약세
- **볼린저 밴드 하단 터치**: 가격 하단 돌파

### ⚡ 실시간 감시
- **10분 간격** 자동 체크
- **일봉 기준** 데이터 분석
- **감시 시간**: 한국 시간 오전 10시 ~ 새벽 4시
- **중복 알람 방지**: 하루 1회 알림 제한

### 🚀 대규모 티커 지원
- **최대 500개** 종목 동시 감시
- **병렬 처리**: 10개 워커로 동시 다운로드
- **자동 재시도**: 네트워크 오류 시 최대 2회 재시도
- **세션 관리**: 리소스 누수 방지 및 타임아웃 처리

### 🎨 직관적인 GUI
- **상태 표시**: 색상 코드화된 동그라미 (🔘 회색: 중지, 🟢 녹색: 실행, 🔴 빨간색: 오류)
- **티커 검색**: 실시간 필터링 기능
- **정렬 가능한 테이블**: 번호/티커/알람 날짜 기준 정렬
- **실시간 로그**: 모든 작업 내역 표시
- **티커 관리**: 추가/삭제/검색 기능

## 🛠️ 설치 방법

### 1. 필수 요구사항
- Python 3.11 이상 (3.11 또는 3.12 권장)
- pip (Python 패키지 관리자)
- Discord 계정 및 서버

### 2. 패키지 설치

```bash
pip install -r requirements.txt
```

**필수 패키지:**
```
discord.py>=2.3.2
yfinance>=0.2.28
pandas>=2.0.0
numpy>=1.24.0
matplotlib>=3.7.0
python-dotenv>=1.0.0
pytz>=2023.3
requests>=2.31.0
```

### 3. 환경 변수 설정

`.env` 파일 생성:

```bash
# Windows
copy env_example.txt .env

# Linux/Mac
cp env_example.txt .env
```

`.env` 파일 내용:
```env
DISCORD_TOKEN=여기에_디스코드_봇_토큰_입력
DISCORD_CHANNEL_ID=123456789012345678
```

### 4. Discord 봇 설정

#### 4-1. 봇 생성
1. [Discord Developer Portal](https://discord.com/developers/applications) 접속
2. **"New Application"** 클릭 → 애플리케이션 이름 입력
3. 좌측 메뉴 **"Bot"** → **"Add Bot"** 클릭
4. **"Reset Token"** → 토큰 복사 → `.env` 파일에 붙여넣기

#### 4-2. 봇 권한 설정
1. 좌측 메뉴 **"OAuth2"** → **"URL Generator"**
2. **SCOPES**: `bot` 체크
3. **BOT PERMISSIONS**: 
   - ✅ `Send Messages`
   - ✅ `Attach Files` (차트 이미지 전송용)
4. 생성된 URL로 봇을 서버에 초대

#### 4-3. 채널 ID 확인
1. Discord 설정 → **"고급"** → **"개발자 모드"** 활성화
2. 알림 받을 채널 우클릭 → **"ID 복사"**
3. 복사한 ID를 `.env` 파일에 붙여넣기

## 📱 GUI 사용 가이드

### 4. 상태 확인
- **상태 표시**: 현재 봇 실행 상태 (색상 코드)

## 🔧 기술적 세부사항

### 지표 계산 방식

#### RSI (Relative Strength Index)
```python
# Wilder's smoothing 방식 사용
# 14일 기준, 과매도: < 35
```

#### MFI (Money Flow Index)
```python
# Typical Price = (High + Low + Close) / 3
# Money Flow = Typical Price × Volume
# 14일 기준, 0으로 나누기 방지 로직 포함
```

#### 볼린저 밴드
```python
# 중심선: 20일 이동평균
# 상/하단: ±1 표준편차
# 터치 조건: Close ≤ Lower Band
```

### 병렬 처리 아키텍처

```
┌─────────────────────────────────────┐
│   Main Thread (GUI + Discord Bot)  │
└─────────────────┬───────────────────┘
                  │
         ┌────────▼────────┐
         │ ThreadPoolExecutor │
         │  (10 workers)      │
         └────────┬───────────┘
                  │
    ┌─────────────┼─────────────┐
    ▼             ▼             ▼
 Worker 1      Worker 2    ... Worker 10
 (Ticker 1)    (Ticker 2)      (Ticker 10)
    │             │             │
    └─────────────┴─────────────┘
                  │
         ┌────────▼────────┐
         │  Result Queue   │
         └─────────────────┘
```

### 에러 처리 및 재시도

```python
# 재시도 가능한 오류
- Timeout errors
- Connection errors
- Empty dataframe

# 재시도 불가능한 오류
- Invalid ticker (상장폐지)
- Missing columns (데이터 구조 오류)
- Insufficient data (< 20 rows)

# 재시도 로직
1차 시도 실패 → 0.5초 대기 → 2차 시도
2차 시도 실패 → 1초 대기 → 3차 시도 (빈 데이터의 경우)
3차 시도 실패 → 최종 실패 로그
```

### 특수 티커 처리

```python
# BRK.B 같은 점(.) 포함 티커
1. BRK.B로 시도
2. 실패 시 BRK-B로 자동 변환 시도
```

## 🐛 문제 해결

### tkinter 오류
```
TclError: Can't find a usable init.tcl
```

**해결 방법:**
1. Python 3.11 또는 3.12 재설치 (tcl/tk 포함)
2. 가상 환경 사용
3. ActiveTcl 수동 설치

### 티커 다운로드 실패

**증상:**
```
❌ BRK.B: 빈 데이터 (티커 존재하지 않음 또는 상장폐지)
⚠️ 실패한 티커 (1개): BRK.B
```

**원인:**
- 특수 문자 티커 (`.` 포함)
- 네트워크 타임아웃
- 잘못된 티커 심볼
- 상장폐지 종목

**해결 방법:**
- ✅ 자동 재시도 (최대 2회)
- ✅ 하이픈 버전 자동 시도 (`BRK.B` → `BRK-B`)
- 📝 로그 확인 후 수동 제거

### MFI 계산 오류

**증상:**
```
❌ COF: 최신 데이터에 NaN 값 존재
```

**원인:**
- 극단적인 상승세로 negative money flow = 0
- 0으로 나누기 발생

**해결 방법:**
- ✅ `neg_mf = 0` → `neg_mf = 1e-10` 자동 대체
- ✅ MFI 범위 제한 (0~100)
